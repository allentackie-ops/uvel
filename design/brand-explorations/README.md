# Uvel icon background exploration

The red sculptural U mark is the fixed brand element. These three 1920 × 1920 concepts explore tactile backgrounds that echo its textile grain:

- `uvel-texture-cream-woven.png` — selected app-icon direction; warm ivory woven canvas most closely matches the supplied reference.
- `uvel-texture-parchment.png` — handmade paper / parchment alternative.
- `uvel-texture-blush-linen.png` — pale blush linen alternative.

The selected cream-woven direction is applied to the app's square icon and matching web/apple raster icon exports. The original adaptive Android foreground layer remains separate to preserve Android masking behavior.
