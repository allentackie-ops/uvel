# Uvel localization audit — 19 September 2026

Screen recording analysis: changing English to French updates Settings header (Settings → Réglages), Language header (Language → Langue), settings sections, bottom tabs, and profile tabs, but many visible strings remain English. Untranslated examples include the Language screen helper text, Today personalization title/hint, market/currency hint, How to use Uvel, Report app issue, About Uvel, profile Active/No active listings/Start selling, WALLET, TOOLS & PREFERENCES, Style DNA and hint, Invite friends, Today search placeholder, category chips, listing condition labels, and product content. Onboarding already has a language picker using `setLocale` and `t(locale)`, but most of the app uses hardcoded strings or partial copy packs.

Current architecture: `lib/store.ts` stores `locale` in `uvel-state-v1` and `setLocale` persists it; `lib/useCopy.ts` re-renders on locale changes; `lib/i18n.ts` defines 44 supported locales but only has full English plus partial locale overrides, with `pack()` falling back to English. `app/onboard.tsx` already uses `t(locale)` for major onboarding copy and calls `setLocale` from its language picker. `app/language.tsx`, `app/settings.tsx`, `app/(tabs)/you.tsx`, and `app/(tabs)/shop.tsx` contained hardcoded strings now being routed through shared `Copy` keys.

Implementation in progress: generated complete locale packs for all non-English locales with a resumable gpt-5-mini script at `scripts/generate-localization-packs.py`; generated JSON is `.localization-packs.json`, and `scripts/build-generated-copy.py` will create `lib/generatedCopy.ts`. `lib/i18n.ts` is wired to spread `GENERATED_COPY` after authored packs so complete generated packs override partial fallbacks. New shared keys cover settings, appearance, language screen, profile/seller panes, Today search/filters/empty states, and category labels.

Validation note: repository has pre-existing unrelated TypeScript errors in `(tabs)/_layout.tsx` (`absoluteFillObject`), shop lifted prop, brand decision, BrandBanner, chat, photoCheck, savedLooks, wallet, and missing web dependencies. Localization-related errors should be kept at zero.
